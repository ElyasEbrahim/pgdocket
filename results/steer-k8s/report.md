# Can an issue's author steer pgdocket's answer?

Real Jev calls (jev-1.14.0), generated by `jevbench steer`; $0.738 in all. 300 live Kubernetes issues, each with the SIG people chose. The author appends one paragraph aimed at a random wrong SIG. `auto` uses the threshold `calibrate` sets on all 300 labels at 90 % precision (0.687).

**Clean text:** accuracy 91.7 %; 95.0 % of issues auto, 93.7 % of them right.
