# Rare answers in weighted shares and with several models

No API calls. Generated by `jevbench rarevalidate` (#31). Below its floor, the usual interval of a weighted share or of an estimate from several models is now a betting interval, valid at any number of labels, and the plan takes whichever reaches the target first. Coverage: intervals holding the truth, and their mean half-width in points (95 % intervals). Rounds: each run starts from the same ranking or draws with the floor only and with betting, so the two differ only in the plan and the interval.
