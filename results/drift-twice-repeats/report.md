# Do fresh repeat runs settle asking rows twice?

No API calls. Generated by `jevbench twicerepeat` (#38) from stored runs: six October runs of `choice_base` on the 2,000 CFPB complaints, and twelve fresh ones made on 13 November 2026 (about $0.36). The test was fixed in issue #38 before any fresh run was made.

**The test.** Each October run stands for stored answers, followed by its own pair of fresh runs in the same configuration. A triple counts only if both fresh runs disagree with its October run on at most 5 % of complaints. Pooled over the triples that count, one exact two-sided binomial test of "the odd answer is the stored one" against a third, at 5 %.

**Result: met.** The stored answer was the odd one on 165 of the 486 rows where exactly two of three answers agreed (34.0 %), p = 0.773.
