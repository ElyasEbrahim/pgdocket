# Should the model check re-ask rows without labels?

No API calls. Generated by `jevbench driftprobes` (#36) from real re-asks. Each check re-asks N labelled anchors in rotation and, with `--probes M`, M rows without labels; the probes add to that check's scores test and to the scores evidence, not to accuracy. #35's split is kept. Detection rate (%) at the first check after the change, and by the last check.

**The test, fixed before the first run:** at the same calls, do the anchors plus as many probes catch changes that begin after the labels have run out more often than twice the anchors, with false alarms at most 5 % and at most 5 points lost at the first check after a change? It failed: probes trade accuracy for scores. So probes are added calls, never a swap for anchors.
