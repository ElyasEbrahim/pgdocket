# Keep-one's votes weighted by length

No API calls: generated by `jevbench steervote` (#48) from the answers #44, #45 and #47 stored. On those, the same code gives every number of theirs it was compared with: 40 for routing (#47), 6 for without the sentence (#45), 20 for yes side (#44).

- **KO** (#43): each piece alone votes for its answer with that answer's probability.
- **KL**: the same vote, times the piece's characters, so every character of the text votes for its piece's answer.
