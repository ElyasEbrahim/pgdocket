# Several models for a weighted share, on real answers

No API calls. Generated by `jevbench multiweightvalidate`. 2,000 CFPB complaint texts judged once, standing for the 21,980 complaints in the source shard that carry them word for word (the heaviest 2,866 times; Kish effective size 26). The share of these complaints about each product is wanted to ± 2 points (95 %). The active version judges every text (setup A: Jev at 20 rows per request; B: Laya), and `--with` adds Jev one row per request, at $23.71 per million texts, on a run of the ranking by weight. Labels cost $1.

Coverage: 1000 draws per cell, a fresh ranking each time; counted where the estimate's own floor holds. Rounds: 100 runs per cell on the texts repeated 500 times.
