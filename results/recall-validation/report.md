# Do recall targets hold on real model errors?

No API calls. Generated by `jevbench recallvalidate`. Each task's judged rows stand in for the population; 1,000 random label draws per cell. *Answered no* is the share of all rows below the chosen threshold, which `auto` would answer *no* without review. *Failure* is a threshold whose true recall is below the target (at most 5 % promised). *Ideal* is the largest share that could be answered *no* if every label were known.
